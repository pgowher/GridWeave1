# Automated semantic adjudication

The active protocol is implemented in paper1/adjudication.py and SEMANTIC_SPECIFICATION.md. A completed study writes populated case comparisons, scoring coverage and disagreement records under runs/<run>/adjudication. LATEST_STUDY.json identifies the latest completed execution.

The earlier blank human-review templates are preserved under archive/v0_2/manual_review_templates. They are optional historical templates, not pending implementation work and not completed human judgments.
